## Durable-state block (this week, one growing script)

1. Swap `MemorySaver` → `PostgresSaver` (`@langchain/langgraph-checkpoint-postgres`).
   Run `setup()`, inspect `checkpoints`, `checkpoint_writes`, `checkpoint_blobs` raw in psql.
2. `interrupt()` inside a subgraph → kill the Node process → restart → resume with
   `Command({ resume })` on the same `thread_id`.
3. Tool that writes to Postgres/Elastic. Crash **after** the write, **before** checkpoint commit.
   Resume, observe duplicate write, fix it (idempotency key or effect recorded in state).
4. `getStateHistory()` → pick an earlier checkpoint → `updateState()` fork → resume.
5. Two threads in parallel; confirm isolation. Decide what `thread_id` means in the work app.

Concepts to own cold: checkpointer vs Store; super-step commit semantics; pending writes;
`checkpoint_ns` for subgraphs; checkpoint retention/deletion policy.
